Royal ဘောက်ချာနှင့် ပို့ဆောင်မှုအခြေအနေ

ဖုန်းနံပါတ်ကိုက်ညီသည့် အမှာစာများကို အလိုအလျောက်စစ်ဆေးပါ။

အလိုအလျောက် Royal sync

Royal မှ official API မပေးထားသည့်အတွက် Chrome extension က သင်ကိုယ်တိုင်ဝင်ထားသော Royal browser session ကို အသုံးပြုပြီး Shipment စာရင်းကို တစ်မိနစ်တစ်ကြိမ် စစ်ဆေးပါမည်။ Waybill အသစ် သို့မဟုတ် အခြေအနေ/ငွေပမာဏ ပြောင်းလဲမှသာ Google Sheet ကို update လုပ်ပါမည်။ Excel/CSV download မလိုပါ။ Browser နဲ့ Royal shipment tab ဖွင့်ထားရန်လိုပြီး Royal password ကို extension က မဖတ်၊ မသိမ်းပါ။

  1. Google Apps Script ထဲသို့ uthk/Code.gs အသစ်ကိုတင်ပြီး လက်ရှိ Web App deployment ကို New version ဖြင့် update လုပ်ပါ။
  2. Repository ရှိ uthk/royal-extension folder ကို Chrome ၏ chrome://extensions စာမျက်နှာမှ Developer mode → Load unpacked ဖြင့် တစ်ကြိမ်ထည့်ပါ။
  3. Royal member account ထဲဝင်ပြီး Your Shipments စာမျက်နှာကို ဖွင့်ထားပါ။
  4. Shipment စာရင်းအပေါ်မှာ UTHK sync အခြေအနေကို မြင်ရပါမည်။ Pause/Resume ကို extension icon မှ ပြောင်းနိုင်ပါသည်။

တူညီသောဖုန်းနံပါတ်အတွက် မချိတ်ရသေးသော Royal delivery order များကို ရက်စွဲအလိုက် ချိတ်ပါမည်။ ရှိပြီးသား Royal Voucher ကို အစားထိုးမည်မဟုတ်ပါ။
