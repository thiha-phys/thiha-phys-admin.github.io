Royal ဘောက်ချာနှင့် ပို့ဆောင်မှုအခြေအနေ

ဖုန်းနံပါတ်ကိုက်ညီသည့် အမှာစာများကို အလိုအလျောက်စစ်ဆေးပါ။

အလိုအလျောက် Royal sync

Royal မှ official API မပေးထားသည့်အတွက် Chrome extension က သင်ကိုယ်တိုင်ဝင်ထားသော Royal browser session ကို အသုံးပြုပါမည်။ Shipment စာရင်းကို တစ်မိနစ်တစ်ကြိမ် စစ်ပြီး waybill အသစ် သို့မဟုတ် အခြေအနေ/ငွေပမာဏ ပြောင်းလဲမှသာ Google Sheet ကို update လုပ်ပါမည်။ Royal password ကို extension က မဖတ်၊ မသိမ်းပါ။

  1. Google Apps Script ထဲသို့ uthk/Code.gs အသစ်ကိုတင်ပြီး လက်ရှိ Web App deployment ကို New version ဖြင့် update လုပ်ပါ။
  2. Repository ရှိ uthk/royal-extension folder ကို Chrome ၏ chrome://extensions စာမျက်နှာမှ Developer mode → Load unpacked ဖြင့် ထည့်ပါ။ Extension ကို ယခင်ထည့်ပြီးသားဖြစ်ပါက ပြင်ဆင်ပြီးတိုင်း Reload လုပ်ပါ။
  3. Royal member account ထဲဝင်ပြီး Your Shipments စာမျက်နှာကို ဖွင့်ထားပါ။
  4. Shipment စာရင်းအပေါ်မှာ UTHK sync အခြေအနေကို မြင်ရပါမည်။ Pause/Resume ကို extension icon မှ ပြောင်းနိုင်ပါသည်။
  5. Statement မှ လိုချင်သောရက်၏ Action ကိုနှိပ်ပြီး detail စာရင်းကိုဖွင့်ပါ။ Extension က Royal VOC, Weight, COD Amount, Delivery, COD Charges, Paid Charges နှင့် Paid Date ကို လက်ရှိ sheet ရှိ Royal Voucher နှင့် တိုက်စစ်ပြီး ဖြည့်ပါမည်။

Statement အချက်အလက်ကို သီးခြား Royal Statement columns ထဲသို့သာရေးပြီး order ၏ မူရင်း Weight, Delivery Fees နှင့် Pay Date ကို မပြောင်းပါ။ Royal Voucher မတွေ့ခြင်း သို့မဟုတ် sheet ထဲတွင် ထပ်နေခြင်းကို မရေးဘဲ အခြေအနေပြပါမည်။
